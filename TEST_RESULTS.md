## Warnings and test-readiness corrections

The production build emitted the non-blocking Vite large-chunk warning; pytest emitted one Starlette/anyio deprecation warning. These are not application browser-console errors. Sustained frame rate, all browser engines and physical mobile/touch devices were not certified. An earlier short sandbox animation sample was approximately13fps, not a60fpspass; the final interaction checks validate working handlers and original speeds, not a new performance certification.

Initial screenshot captures occasionally showed loading placeholders, the first mobile assertion ran after a screenshot workflow left the shared browser onabout:blank, and an initial spin-state assertion read the DOM before React committed. The delivered completed-page captures and affected checks were redone with correct app origin/readiness/state commit. Initial harness failures remain documented in `validation/final/browser/harness_notes.md`, not mislabeled as passes.
