# Decorative assets and licenses

The original frontend’s imagery-loading/fallback behavior remains. Earth and Moon textures are local byte copies of the originally referenced Three.js example image URLs; their original project reference is https://github.com/mrdoob/three.js (MIT project, NASA-derived planetary example imagery). Source URLs and file hashes are in `validation/decorative_assets.json`. Original thumbnails/Unsplash fallback URLs remain unchanged.

The original Mars NASA/turban URLs returned HTTP404. A local replacement by **Solar System Scope** uses **Creative Commons Attribution4.0**: https://www.solarsystemscope.com/textures/ and https://creativecommons.org/licenses/by/4.0/ . The2kMars map is a decorative equirectangular visual texture. Its publisher explicitly describes color tuning and fictional gap filling; it is not a validated thermal/elevation/mineral raster. Attribution is included in the UI andthisfile. Existing original globe code/lighting/atmosphere/orbit/fallback chains remain.

No new scientific NASA datasets were acquired. No decorative texture drives temperatures, slopes, mineral quantities, evidence ranks, or safety claims.
